# Task Manager App

A clean, modern task manager mobile application built with React Native and Expo. It features real-time search, category and priority tagging, filter views, offline persistence and a Dark/Light theme toggle.

## Features

### Core Capabilities
* **Task Management:** Create, check off, and delete tasks with instant UI updates.
* **Categories & Priority Badges:** Categorize tasks under Work, Personal, Study, or Health, and assign High, Medium, or Low priorities.
* **Instant Search & Status Filters:** Real-time search by keywords along with status filter tabs (All, Active, Completed) and category pills.
* **Dark & Light Mode:** Built-in theme switcher with theme persistence.
* **Offline Persistence:** Uses AsyncStorage to save tasks and user theme settings locally on the device.
